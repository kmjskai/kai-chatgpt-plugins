# Kai iCloud Calendar

在对话中查看 Mac 已同步的日历，并按确认的安排创建日程。

[English](README.en.md)

## 主要能力

- 列出日历及其是否可写。
- 按时间、日历或标题查询日程，展开已有重复日程的实例。
- 在明确确认后创建一个非重复事件，并读取保存结果进行核对。

## 开始使用

需要 macOS 14+、Apple Silicon、Node.js 20+，以及支持本地 MCP 的客户端。先在 macOS 日历中配置好账户，再安装此插件并新建本地会话。

你可以说：“看看我明天有什么安排”“查询这个周末的课程”。创建事件时，请明确日历、标题、起止时间与时区、是否全天，以及适用的地点、备注和提醒。

首次调用可能请求 **Kai Apple Calendar Helper** 的日历完全访问权限。系统没有独立的只读授权选项；实际操作仍以本次明确请求和工具范围为限。

## 数据与隐私

通过 macOS EventKit 读取本机日历数据库，账户同步交给系统。无需把 Apple 密码交给插件。查询结果返回当前 AI 客户端，按其数据处理规则使用；插件不另行保存日历内容日志。

本插件可以看到系统中可访问的多个日历账户。它不提供独立云端连接，也不切换国际站或中国大陆站。它是独立工具，与 Apple、OpenAI 的官方 iCloud 插件无隶属关系。

## 限制与恢复

当前不提供修改、删除和创建重复事件。若创建结果不明确，先查询已有日程再决定是否重试。

数据缺失时，先在 macOS 日历中确认同步；权限不足时，在系统设置的“隐私与安全性 → 日历”中检查助手授权。手机和纯网页会话无法直接运行此助手。

使用 `codex plugin remove kai-icloud-calendar@kai-chatgpt-plugins` 卸载。卸载不会删除事件，也不会自动撤销系统日历权限。

构建源码位于 `server/`。在该目录执行 `npm run build` 与 `npm test` 可构建并检查 MCP。重建的助手使用本地临时签名；正式分发的 Developer ID 签名和公证是额外步骤。
